The upstream reference uses Issue 9, dated 2025-01-15. For strict work, use the issue requested by the user. If no issue is specified, check the official site for the current issue.

## Strict English work

Read the applicable official rules and dictionary. Check approved word meanings, parts of speech, allowed forms, technical nouns and verbs, and the relevant procedural or descriptive rules. Use the standard's word-count conventions.

The upstream Issue 9 map points to rule 1.11 for consistent technical nouns, section 5 for procedures, and section 6 for descriptions. Treat these pointers as navigation aids. The complete official issue is the authority.

Record which issue and checks you used. Distinguish a draft from verified compliance. Identify missing references and checks you could not complete. An AI-generated draft or a simple word counter does not establish compliance.

## Polish and ordinary code explanations

Use the practical clarity rules in SKILL.md. Polish is an adaptation of the writing principles. It is not Simplified Technical English. The "80%" mode is qualitative in both languages.

Screenshots or generated examples in social-media posts are not authoritative dictionary references. Use the official issue when sources disagree.
